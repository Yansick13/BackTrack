# BackTrack — UWI Mona Campus Lost & Found System

**COMP2140 Software Engineering Group Project**  
A Lost & Found web application built for the UWI Mona Campus Police to replace manual station diary logging with automated matching, blinded public listings, and auditable claim verification.

---

## Tech Stack
* **Backend:** Python 3, Flask, Flask-SQLAlchemy
* **Database:** SQLite (`backtrack.db`)
* **Frontend:** HTML5, Jinja2 Templates, Bootstrap 5
